# 🎨 Interior Designers

This folder contains AI skills designed specifically for **interior design workflows** using **Claude AI** and **OpenAI Codex**.

Use these files to improve:

- Client brief interpretation
- Technical drawing reading
- RCP and ceiling legend interpretation
- Floor and wall finish legend reading
- Material and finish review
- FF&E checks
- Moodboard and concept refinement
- Material schedule generation
- Finish schedule validation
- BOQ and quantity review
- Unit understanding: mm / cm / m
- Interior technical detailing logic
- Drawing QA before delivery

## 🧠 Claude AI Skills for Interior Designers

Use **Claude AI** for:

- Design thinking and reasoning
- Technical drawing interpretation
- RCP, floor, wall, and ceiling legend understanding
- Material and finish schedule generation
- FF&E schedule review
- Ergonomics and circulation review
- Interior detail logic and coordination notes
- Design QA comments and recommendations

Claude AI is strongest when you need to **understand, explain, compare, review, and reason through design information**.

## ✅ How to Add the Skill

1. Open the needed folder.
2. Open `skill-library.md`.
3. Copy the **Add the Skill** prompt block.
4. Paste it into Claude AI, Codex, or your project AI workspace.
5. Replace the placeholders with your real project data.
6. Save repeated prompts as reusable project skills.
