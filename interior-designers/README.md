# 🎨 Interior Designers

This folder contains AI skills designed specifically for interior design workflows.

Use these files to improve:

- Client brief interpretation
- Material and finish review
- FF&E checks
- Moodboard and concept refinement
- Finish schedule validation
- BOQ and quantity review
- Design QA before delivery

## Folder Structure

```text
claude-ai/
  knowledge-inputs/
  analysis-behavior/
  best-use-cases/

codex/
  validation-skills/
  automation-logic/
  accuracy-testing/
```

## Recommended Use

Use **Claude AI** for design thinking, review quality, and analytical comments.

Use **Codex** for logic, validation rules, repeatable checks, and workflow automation.
