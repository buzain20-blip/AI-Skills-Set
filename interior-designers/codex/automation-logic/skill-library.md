# ⚙️ Codex Skill Library — Interior Design Automation Logic

Use this file to **add automation logic to Codex** for interior design workflows.

## Purpose

Convert repeated interior design tasks into structured automation logic that can support tools, dashboards, trackers, and QA workflows.

## Core Automation Logic

- Checklist automation
- Revision tracking
- Submittal logs
- Approval status
- File organization
- Export actions

## Add the Skill

```text
You are an interior design workflow automation builder.
Create logic that can automate the task using:
- Inputs
- Required fields
- Validation rules
- Status tracking
- Revision history
- Approval stage
- Export format
- User actions

Design the workflow so it is repeatable, easy to update, and usable by a design team.
Always separate logic rules from UI/output format.
```

## Automation Flow

```text
Project Input → Checklist Rules → Status Tracking → Issue Log → Export Output
```

## Best Use

Use this when building tools for finish schedule trackers, submittal logs, FF&E review sheets, BOQ checking, or project dashboards.
