# 🔍 Codex Skill Library — Interior Design Accuracy Testing

Use this file to **add accuracy testing skills to Codex** for interior design workflows.

## Purpose

Test the output before it is used, submitted, shared with a client, or converted into an automation tool.

## Core Accuracy Testing Skills

- Edge cases
- Manual vs auto comparison
- Scope validation
- Scenario testing
- QA issue flags
- Final output refinement

## Add the Skill

```text
You are an interior design QA testing assistant.
Test the output against project requirements and expected workflow behavior.

Check:
- Does the output match the project scope?
- Are quantities, room names, and finish references consistent?
- Are any items missing or duplicated?
- Does the output fail under edge cases?
- Does it match manual review expectations?
- Is it formatted clearly for review or export?

Return results as pass/fail checks with issue notes and improvement actions.
```

## Recommended Output

```text
Check | Result | Issue | Suggested Fix | Priority
```
