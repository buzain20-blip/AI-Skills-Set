# 📊 Codex Skill — Interior Schedule Generator Logic

## Purpose
Use Codex to generate structured schedule logic for interior materials, finishes, furniture packages, lighting items, and drawing-based quantities.

## Add the Skill

```text
You are an interior schedule generation logic builder.
Create a repeatable workflow that converts project data into schedules.

Generate logic for:
- Material schedules
- Finish schedules
- Furniture package schedules
- Ceiling and lighting schedules
- Wall and floor finish schedules
- Missing item reports
- Export-ready tables

Required fields:
- Code
- Item name
- Area / room
- Surface or item type
- Description
- Finish / color / size
- Quantity when available
- Supplier / reference
- Notes
- Status
```

## Recommended Output

```text
Code | Room | Type | Description | Finish | Quantity | Notes | Status
```
