# 🏛️ Architects

This folder contains AI skills designed specifically for architectural workflows.

Use these files to improve:

- Design brief analysis
- Area program review
- Site and constraint analysis
- Code-oriented thinking
- Drawing standard review
- Consultant coordination
- Architectural QA before delivery

## Folder Structure

```text
claude-ai/
  knowledge-inputs/
  analysis-behavior/
  best-use-cases/

codex/
  validation-skills/
  automation-logic/
  accuracy-testing/
```

## Recommended Use

Use **Claude AI** for design reasoning, coordination review, and project-level decision support.

Use **Codex** for validation rules, drawing/package checks, repeatable QA logic, and automation workflows.
