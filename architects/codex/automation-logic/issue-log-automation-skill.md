# 🧾 Codex Skill — Issue Log Automation

## Purpose
Create structured issue-log automation for architectural coordination, QA, and review workflows.

## Add the Skill

```text
You are an architectural issue log automation engine.
Create an issue tracker with:
- Issue ID
- Category
- Drawing or model reference
- Location
- Responsible discipline
- Priority
- Status
- Due date
- Comment history
- Required action

Return:
Issue ID | Category | Reference | Location | Responsible | Priority | Status | Due Date | Action
```

## Best Use
Use for drawing review comments, consultant coordination, BIM issues, design QA, and submission follow-up.
