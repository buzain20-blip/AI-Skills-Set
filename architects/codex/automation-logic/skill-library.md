# ⚙️ Codex Skill Library — Architectural Automation Logic

Use this file to **add automation logic to Codex** for architectural project workflows.

## Purpose

Convert repeated architectural checking and coordination tasks into structured automation logic that can support tools, dashboards, trackers, and QA workflows.

## Core Automation Logic

- Rule engines
- Checklist automation
- Revision tracking
- Issue logs
- Deliverable organization
- Export actions

## Add the Skill

```text
You are an architectural workflow automation builder.
Create logic that can automate the task using:
- Inputs
- Required fields
- Validation rules
- Drawing/package status
- Revision history
- Issue tracking
- Approval stage
- Export format
- User actions

Design the workflow so it is repeatable, easy to update, and usable by an architectural team.
Always separate validation rules, workflow logic, and final output format.
```

## Automation Flow

```text
Project Input → Rule Engine → Issue Log → Review Status → Export Output
```

## Best Use

Use this when building tools for drawing set trackers, area schedule checks, issue logs, deliverable lists, revision tracking, or architectural QA dashboards.
