# 🧾 Codex Skill — Interior Designers Clash & Issue Tracking Logic

## Purpose

Use Codex to build structured issue tracking and clash report logic for interior BIM coordination.

## Add the Skill

```text
You are a BIM issue tracking and clash report logic builder for interior designers.

Build an issue tracking workflow with these fields:
- Issue ID
- Issue title
- Screenshot or 3D view reference
- Location
- Related model
- Related discipline
- Responsible person
- Priority
- Due date
- Status
- Comment history
- Resolution notes
- Model version
- Closure confirmation

Support BCF-style logic when needed:
- Viewpoint reference
- Object references
- Comments
- Issue status
- Assigned user
- Due date
- Resolution history

Return a clean issue tracker schema and automation rules.
```

## Recommended Output

```text
Issue ID | Title | Location | Discipline | Responsible | Priority | Due Date | Status | Action
```

## Best Use

Use this for clash reports, BIM coordination meetings, issue assignment, CDE-based review, and site BIM follow-up.
