# 🏗️ Structural Engineers — BIM Workflow Skills

This folder contains BIM workflow skills for **structural engineering BIM teams**.

## AI Roles

- `claude-ai/` → BIM review, structural coordination reasoning, model interpretation, and execution guidance
- `codex/` → validation rules, opening/penetration checks, clash tracking, and automation outputs

## Structural BIM Focus

- Structural model setup
- Grids and shared levels
- Beams, columns, slabs, foundations, and structural framing
- Openings and penetrations
- Architecture and MEP coordination
- Clash detection and issue resolution
- Construction support and as-built structural updates
