# 🏗️ BIM Workflow AI Skills Set

A professional BIM workflow skills library for **Claude AI** and **OpenAI Codex**, organized by separated AEC disciplines.

This folder converts the full BIM workflow into reusable `.md` skills for:

- 🎨 Interior Designers
- 🏛️ Architects
- 🌬️ MEP Engineers / Mechanical
- ⚡ MEP Engineers / Electrical
- 🚰 MEP Engineers / Plumbing
- 🚧 Civil Engineers
- 🏗️ Structural Engineers

---

## 🎯 Purpose

Use this BIM workflow skills set to support:

- Project Setup & BIM Requirements
- BIM Execution Plan creation and review
- Model Authoring
- Model Coordination
- Clash Detection
- Issue Tracking
- Design Review & Approval
- Drawing & Documentation Production
- Quantity Takeoff & BOQ Support
- Construction / Site BIM Support
- As-Built Model & Handover

---

## 🧠 Claude AI Role

Claude AI acts as the **BIM thinking + execution guidance engine**.

Use Claude AI to:

- Read and interpret BIM requirements
- Review BIM Execution Plans
- Analyze model coordination issues
- Understand technical drawing logic
- Generate execution guidance
- Support site coordination and RFI clarification
- Review handover readiness

---

## ⚙️ Codex Role

Codex acts as the **BIM validation + automation engine**.

Use Codex to:

- Build validation rules
- Automate file naming checks
- Create CDE and revision logic
- Structure clash and issue trackers
- Validate BOQ / quantity extraction
- Generate QA tables and dashboards
- Check as-built and handover packages

## ✅ How to Add the Skill

1. Open your discipline folder.
2. Choose `claude-ai` for review, interpretation, reasoning, and execution guidance.
3. Choose `codex` for validation rules, automation logic, and repeatable QA.
4. Open the `.md` file.
5. Copy the **Add the Skill** prompt block.
6. Paste it into Claude AI, Codex, or your project AI workspace.
7. Replace placeholders with your real project data, model rules, schedules, drawings, clash reports, or deliverables.
