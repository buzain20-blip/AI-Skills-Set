# 🏗️ BIM Workflow AI Skills Pack

A structured BIM workflow skills set for **Claude AI** and **OpenAI Codex**, created for:

- Interior Designers
- Architects
- MEP Engineers
- Civil & Structural Engineers

This pack converts the BIM workflow sequence into reusable AI skills that support BIM planning, model setup, coordination, clash reporting, quantity support, construction support, and as-built handover.

---

## 🔁 BIM Workflow Sequence

```text
Brief
→ BIM Requirements
→ BIM Execution Plan
→ Model Setup
→ Discipline Modeling
→ Coordination
→ Clash Detection
→ Issue Resolution
→ Drawing Production
→ Quantity Takeoff
→ Construction Support
→ As-Built Handover
```

---

## 🧠 Claude AI vs ⚙️ Codex

### Claude AI is strongest for:
- Understanding project requirements
- Reviewing BIM Execution Plans
- Reading coordination risks
- Interpreting BIM workflows
- Reviewing deliverables
- Producing clear QA recommendations

### OpenAI Codex is strongest for:
- Creating validation rules
- Automating file naming checks
- Structuring clash issue trackers
- Checking schedule/data consistency
- Producing issue logs and QA tables
- Supporting BIM automation tools
