# 🚰 Plumbing Engineers — BIM Workflow Skills

This folder contains BIM workflow skills for **plumbing BIM teams**.

## AI Roles

- `claude-ai/` → BIM review, plumbing coordination reasoning, clash interpretation, and execution guidance
- `codex/` → validation rules, fixture checks, drainage/water supply issue tracking, and automation outputs

## Plumbing BIM Focus

- Water supply and drainage model coordination
- Sanitary fixture coordination
- Shafts, risers, and wet area coordination
- Drainage slopes and ceiling void coordination
- Access points, cleanouts, and maintenance zones
- Coordination with architecture, interiors, structure, and other MEP systems
- Site support and as-built plumbing model control
