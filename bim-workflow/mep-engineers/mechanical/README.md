# 🌬️ Mechanical Engineers — BIM Workflow Skills

This folder contains BIM workflow skills for **mechanical / HVAC BIM teams**.

## AI Roles

- `claude-ai/` → BIM review, HVAC coordination reasoning, clash interpretation, and execution guidance
- `codex/` → validation rules, equipment checks, clash tracking logic, and automation outputs

## Mechanical BIM Focus

- HVAC model requirements
- Duct routing and ceiling coordination
- Diffusers, grilles, FCUs, AHUs, and equipment zones
- Mechanical room coordination
- Access and maintenance clearances
- Clash resolution with structure, architecture, lighting, ceilings, and other MEP services
- Site support and as-built mechanical model control
