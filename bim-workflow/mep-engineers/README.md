# 🧰 MEP Engineers — BIM Workflow Skills

This folder separates MEP BIM skills into three disciplines:

- 🌬️ `mechanical/`
- ⚡ `electrical/`
- 🚰 `plumbing/`

Each discipline includes:

- `claude-ai/` → BIM review, interpretation, coordination reasoning, and execution guidance
- `codex/` → validation rules, automation logic, clash tracking, and QA outputs

## MEP BIM Focus

MEP BIM workflows should support:

- Ceiling coordination
- Service routing
- Equipment clearance
- Maintenance access
- Clash detection
- Issue tracking
- Construction coordination
- As-built handover

## Recommended Workflow

```text
MEP Requirements
→ BEP Review
→ Discipline Model Setup
→ Model Authoring
→ Coordination
→ Clash Detection
→ Issue Tracking
→ Drawing Production
→ Site Support
→ As-Built Handover
```
