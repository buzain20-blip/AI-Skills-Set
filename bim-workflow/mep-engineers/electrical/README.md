# ⚡ Electrical Engineers — BIM Workflow Skills

This folder contains BIM workflow skills for **electrical BIM teams**.

## AI Roles

- `claude-ai/` → BIM review, electrical coordination reasoning, clash interpretation, and execution guidance
- `codex/` → validation rules, lighting/power/data checks, issue tracking, and automation outputs

## Electrical BIM Focus

- Lighting model coordination
- Power and data outlet coordination
- Containment and cable tray routes
- Electrical panels and access clearances
- Emergency lighting and sensor coordination
- Ceiling coordination with interiors, mechanical, and firefighting
- Site support and as-built electrical model control
